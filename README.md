# Frog Pond

Um sapo na beira de um lago gerado, comendo o que voa por cima dele.

**Site do jogo, com as novidades de cada versão:**
[jeffersonest.github.io/frog-pond-launcher](https://jeffersonest.github.io/frog-pond-launcher/)

## Baixar

| Sistema | Arquivo |
| --- | --- |
| Windows (instalador) | [frog-pond-setup.exe](https://github.com/jeffersonest/frog-pond-launcher/releases/latest/download/frog-pond-setup.exe) |
| Windows (ZIP, sem instalar) | [frog-pond-windows.zip](https://github.com/jeffersonest/frog-pond-launcher/releases/latest/download/frog-pond-windows.zip) |
| Linux (AppImage) | [frog-pond-x86_64.AppImage](https://github.com/jeffersonest/frog-pond-launcher/releases/latest/download/frog-pond-x86_64.AppImage) |
| Linux (Debian, Ubuntu) | [frog-pond-amd64.deb](https://github.com/jeffersonest/frog-pond-launcher/releases/latest/download/frog-pond-amd64.deb) |
| Linux (arquivo .tar.gz) | [frog-pond-linux-x86_64.tar.gz](https://github.com/jeffersonest/frog-pond-launcher/releases/latest/download/frog-pond-linux-x86_64.tar.gz) |

O download traz o jogo completo junto com um launcher. A partir daí o launcher cuida das
atualizações sozinho: ao abrir, ele compara o que você tem com o que foi publicado aqui e baixa só
a parte que mudou. Uma correção de jogo costuma ser pouco mais de um megabyte.

Sem internet o jogo abre do mesmo jeito, com a versão que já está instalada.

## O que tem neste repositório

Só o que é preciso para baixar e atualizar o jogo: os instaladores, os pacotes que o launcher
busca e o `manifest.json` que diz qual é a versão atual. O código-fonte fica em outro lugar.
